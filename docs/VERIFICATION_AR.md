# حالة التحقق

هذه حزمة مصدر قيد التنفيذ، وليست إصدارًا مجرّبًا قابلًا للتثبيت حتى الآن.

## ما تحقق فعليًا

- جُلبت بيانات riwayat وreciters وsuwar من MP3Quran API.
- الفهرس يحتوي على 20 رواية معيارية، 10 قراءات، 114 اسم سورة و274 مصحفًا مصنّفًا فرديًا.
- المصدر يغطّي 13 رواية فرديًا؛ 7 روايات غير متاحة منفردة.
- جرى فحص طلب Range حقيقي لأول سورة مدرجة في كل مصحف: 274/274 أعادت HTTP 206 مع Content-Type audio/mpeg وCORS: *.
- لا يعني فحص عينة من كل مصحف أن جميع السور البالغ عددها الآلاف قد اختُبرت، ولا أنه تم تدقيق الرواية بالاستماع البشري.
- تحقق بنيوي مستقل نجح للفهرس وربط الروايات وYAML وXML وJSON.
- تم تنزيل عينة صوت حقيقية وفحصها بواسطة ffprobe: MP3، مدة 61.12 ثانية، 22050Hz. التفاصيل في decoder-probe.json.
- تنسيق وفحص بناء جمل Dart بواسطة dart format؛ هذا لا يساوي Flutter analyze.

## ما لم يتحقق بعد

- Flutter pub get/analyze/test للمشروع، وبناء APK وWeb.
- نجاح GitHub Actions أو إنشاء مستودع أو نشر Vercel.
- تشغيل الصوت داخل التطبيق وتجربة التنزيل المحلي الفعلية على أندرويد وSafari.
- التخطيط البصري عند عرض 320px و390px والنص المكبر.
- الخلفية والإشعارات، والتنقل التلقائي مع سياسات Safari.
- حدود حصة التخزين والطرد عند امتلاء مساحة iPhone.
- إعادة الاستئناف عند الشبكة الضعيفة أو تغيير الملف على الخادم.

## عوائق البيئة

لم تكتمل موافقة الدخول للمتصفح، وموصل GitHub لا يتيح إنشاء مستودع جديد. رفضت المراجعة التلقائية استمرار أمر Flutter بعد رصد محاولة وصول لخدمة بيانات البيئة السحابية؛ لم نتجاوز الرفض ولم ندّع نجاح البناء.

## قبول الإصدار قبل التسليم النهائي

1. إنشاء المستودع الخاص ورفع المصدر دون أي أسرار.
2. تشغيل CI، إصلاح أخطاء التحليل والاختبارات والبناء حتى نجاحه.
3. تثبيت APK وتجربة: رواية ← قارئ ← سورة، تقديم/تأخير، التالي، تكرار، استكمال.
4. تنزيل سورة ثم فصل الشبكة وإعادة فتح التطبيق وتشغيلها؛ حذفها والتحقق من زوالها.
5. تنزيل مصحف جزئي والتأكد أنه لا يعرض 114 سورة، وإيقاف التنزيل واستئنافه.
6. نشر Web واختبار Safari وPWA، ثم إعادة التحميل دون إنترنت بعد اكتمال تثبيت shell.
7. قياس تجربة الذاكرة عند السور الطويلة؛ تنزيل الويب الحالي يحتفظ بالسورة مؤقتًا في الذاكرة قبل حفظها في IndexedDB.
8. الحصول على تأكيد حقوق الاستخدام قبل إطلاق تجاري أو إعادة استضافة.
