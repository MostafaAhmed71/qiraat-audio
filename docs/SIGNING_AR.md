# توقيع أندرويد

البناء العادي ينتج APK بوضع Release لكنه موقّع بمفتاح Debug الخاص بمشغّل CI؛ يصلح للتجربة وليس للنشر النهائي. قد يتغير هذا المفتاح بين تشغيل وآخر، وقد يتطلب تثبيت نسخة جديدة حذف النسخة القديمة وفقد بياناتها المحلية.

لا يوجد مفتاح أو كلمة مرور في المستودع. عند توفير مفتاح توزيع دائم، توضع القيم مباشرة في GitHub Actions Secrets دون إرسالها في المحادثة:

- ANDROID_KEYSTORE_BASE64
- ANDROID_STORE_PASSWORD
- ANDROID_KEY_PASSWORD
- ANDROID_KEY_ALIAS

ملف key.properties يُنشأ مؤقتًا أثناء البناء، ويُحذف مع ملف المفتاح في خطوة always. لا تدخل ملفات التوقيع ضمن Artifacts.

سير Release يعمل عند Tag بنمط v1.2.3، ويتأكد أن الالتزام ضمن main، ويشترط الأسرار الأربعة. يفشل بوضوح إذا لم تتوفر، ولا ينشر APK بمفتاح Debug باسم إصدار نهائي. قبل تفعيل توقيع التوزيع، يوصى بحماية main وقصر تعديل workflows على المراجعين الموثوقين.

لم يُشغّل أي workflow بعد؛ المستودع لم يُنشأ بعد بسبب عدم اكتمال الدخول للمتصفح.
