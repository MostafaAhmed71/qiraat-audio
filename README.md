# Qiraat Audio — القراءات العشر

تطبيق Flutter عربي RTL للصوتيات فقط. **نسخة تجريبية منشورة:** https://qiraat-audio.vercel.app/

المستودع Public بموافقة صاحب المشروع. راجع تقرير التحقق لتمييز الاختبارات المنفذة عن اختبارات الأجهزة الفعلية غير المنفذة.

## المنجز في المصدر

- 8 شاشات: الرئيسية، الروايات، القراء، السور، المشغل، التنزيلات، المفضلة، الإعدادات.
- Riverpod، GoRouter، just_audio وjust_audio_background لأندرويد.
- فهرس مضمّن دون إنترنت، محفوظ من API الحقيقي مع ربط rewaya_id.
- تشغيل محلي تلقائي، حفظ الموضع، التالي/السابق، تقديم وتأخير، تكرار.
- تنزيل سورة أو جميع السور المتاحة، قائمة متتابعة، تقدم، حذف، إيقاف/استئناف ضمن الجلسة.
- أندرويد: ملفات خاصة بالتطبيق وملفات جزئية مع Range عندما يقبله الخادم. قائمة التنزيل لا تستمر بعد إنهاء التطبيق؛ يُعاد طلب التنزيل ليستأنف الملف الجزئي.
- الويب: IndexedDB، إلغاء السورة غير المكتملة وإعادتها من البداية، shell PWA كامل بمحرك محلي. لا ضمان لتخزين Safari الدائم أو العمل في الخلفية.
- CI للبناء والاختبار وArtifacts؛ وRelease tags تشترط مفاتيح توقيع آمنة.

## بيئة التطوير وCI

Flutter 3.35.4 (commit d693b4b9dbac2acd4477aea4555ca6dcbea44ba2)، Java 17، Gradle 8.12، AGP 8.9.1، Kotlin 2.1.0. التبعيات المباشرة مثبتة في pubspec.yaml، وملف pubspec.lock مأخوذ من بناء ناجح ومُعتمد في المستودع. يحفظ CI نسخة من القفل المحلول كـ Artifact باسم qiraat-audio-dependency-lock.

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
flutter build web --release --no-web-resources-cdn --pwa-strategy=none
python3 tool/pwa.py
```

هذه الأوامر مخصصة لمشغّل السحابة وCI، ولا يُطلب من صاحب المشروع تشغيلها محليًا.

Vercel: ملف vercel.json يبني من المصدر عبر tool/vercel-build.sh؛ تم إنشاء مشروع Vercel ونشر أول نسخة من مصدر GitHub. يستخدم GoRouter عناوين hash الافتراضية لتجنب مشاكل المسارات. لـ GitHub Pages يلزم البناء بـ --base-href /qiraat-audio/ ثم تشغيل tool/pwa.py؛ نشر Pages من مستودع خاص يعتمد على خطة الحساب ولا يتم تحويل المستودع إلى عام تلقائيًا.

## التثبيت عند نجاح البناء والنشر

أندرويد: تنزيل APK من Artifacts وفك حاوية ZIP إن أضافها GitHub، ثم السماح بالتثبيت من المتصفح وفتح الملف. نسخة CI غير الموقعة بإعداد توزيع دائم تستخدم Debug key ولا تمثل إصدار متجر.

iPhone: فتح رابط النشر في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية. فتح التطبيق أولًا باتصال، وانتظار اكتمال تحميل الواجهة، وتنزيل السور المطلوبة مع إبقاء التطبيق مفتوحًا. اختبر السورة بعد فصل الشبكة؛ قد يحذف المتصفح البيانات لاحقًا.

## المعصراوي على الويب وأندرويد

المعصراوي يظهر أول قائمة القراء في جميع الروايات. روابط ن للقرآن مباشرة من قوائمه الأصلية، دون إعادة استضافة. يمكن الاستماع عبر الويب، لكن تنزيل هذه الملفات داخل المتصفح غير متاح بسبب غياب CORS على المصدر؛ زر التنزيل معطل مع توضيح السبب. تطبيق أندرويد يدعم تنزيلها، مع التحقق من مقدمة MP3 لأن المصدر يرسل application/octet-stream. حفص الكامل من MP3Quran يبقى قابلًا للتنزيل على الويب أيضًا.
